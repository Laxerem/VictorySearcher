# TASK.md — VictorySearcher

## Что это
Внутренний инструмент для HR и коммерции. Две независимые фичи под одним URL.

---

## Фича 1: Скоринг резюме (LLM)

**Задача:** Рекрутёр создаёт вакансию, загружает список резюме → система ранжирует их по релевантности.

**Поведение:**
- Пользователь заполняет вакансию (название, описание, требования, дополнительные требования)
- Загружает резюме в форматах TXT, DOCX и PDF
- Просматривает список загруженных резюме: отображается их статус (проверено / ожидает проверки), счётчики проверенных и непроверенных
- Открывает текстовое содержимое резюме прямо в интерфейсе или скачивает оригинальный файл
- Запускает скоринг → процесс идёт в фоне с отображением прогресса в реальном времени; инкрементный режим: повторный запуск обрабатывает только непроверенные резюме
- Получает отсортированный список резюме с оценками

**Оценка резюме включает:**
- `overall` — итоговый балл (0–100)
- `experience` — релевантность опыта, его качество и глубина (0–50)
- `skills` — соответствие хард-скиллов (0–40)
- `extra` — соответствие дополнительным требованиям к вакансии (0–10)
- `reasoning` — текстовое обоснование оценки кандидата на русском
- `requirementsAnalysis` — детальный разбор по каждому пункту требований: соответствует ли кандидат и текстовое подтверждение из резюме

**Флаги неопределённости:**
Если система не уверена в оценке кандидата, резюме помечается флагом и выводится в отдельную секцию «Требуют внимания» — под основным ранжированным списком.

**Форматы резюме:**
- Принимаются файлы `.txt`, `.docx` и `.pdf`; из каждого извлекается текст для скоринга

## Фича 2: Аналитика рынка труда

**Задача:** Автономный сбор данных о вакансиях с HH и SuperJob для заданных ролей. Обновляется ежедневно без ручного запуска.

**Поведение:**
- Администратор задаёт список «целевых ролей» (например: «Python Developer», «HR Business Partner»)
- Каждую ночь система собирает вакансии с обоих источников
- Пользователь видит дашборд аналитики по каждой роли

**Метрики аналитики:**
- Средняя / медианная ЗП по роли (диапазон min/max/median)
- Динамика ЗП по времени (последние N снимков)
- Топ навыков в вакансиях (частота упоминания)
- Количество вакансий / конкуренция (сколько компаний ищут)

**Источники:**
- HH (api.hh.ru) — обязательно
- SuperJob (api.superjob.ru) — второй источник

## Авторизация

- Один тестовый аккаунт (username + password) из конфигурации
- JWT-токен при логине
- Нет регистрации, нет ролей

---

## Нефункциональные требования

- Сервис работает **автономно** (без ручного запуска фоновых задач)
- Деплой **локально** на машине предприятия (Docker Compose)
- Уважение лимитов внешних API (задержки, кэш 24ч)
- Данные о зарплатах и резюме хранятся локально (безопасность)

---

## Что НЕ входит в скоуп (явно)

- Регистрация пользователей
- Мобильный интерфейс
- Интеграция с ATS/CRM
- Добыча резюме с внешних источников (резюме загружает рекрутёр сам)
