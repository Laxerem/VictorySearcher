# История работы с ИИ

## Эпизоды

### Продумывание архитектуры (Backend)

#### Отказ от решений

1. Claude предлагал MediatR (Command/Handler CQRS) для Application слоя — отвергнуто, потому что количество обработчиков невелико (два главных сервиса: скоринг и аналитика), MediatR добавляет накладные расходы без реальной пользы в данном масштабе.

### Авторизация

**Контекст:** Реализация JWT-авторизации для единственного системного пользователя. Регистрации нет — пользователь создаётся через seed при старте приложения. Логин и пароль из конфига передаются в `JwtOptions`. Успешный логин возвращает Bearer-токен, который клиент передаёт в заголовке `Authorization`. Параллельно был создан агент `dotnet-senior` как результат рефлексии над допущенными ошибками.

#### Отказ от решений

1. Claude поместил генерацию JWT-токена внутрь `AuthService` — отвергнуто, потому что это нарушает SRP: проверка учётных данных и генерация токена — разные ответственности. Генерация вынесена в отдельный `JwtProvider`.
2. Claude вернул `string?` из `IAuthService.LoginAsync` вместо `Result<string>` — отвергнуто, потому что в проекте принят `Result<T>` для ожидаемых ошибок сервисного слоя, это прямо прописано в CLAUDE.md.
3. Claude использовал анонимный тип `new { token }` и `IActionResult` в контроллере — отвергнуто, потому что контракты API должны быть типизированными `record`-типами в папке `Contracts/`, а контроллер всегда возвращает `ActionResult<TResponse>`.

### Разработка скоринга резюме (VictorySearcher.Service)

**Контекст:** Реализация базовой версии скоринга: загрузка резюме, парсинг текста, отправка в LLM и сохранение результатов. В процессе работы потребовался рефакторинг для устранения жёсткой связанности и нарушений SRP, допущенных в первоначальной реализации.

#### Отказ от решений

1. Claude создавал `OpenAIClient` прямо внутри метода `ResumeAnalyserService.AnalyseAsync` — отвергнуто, потому что это нарушает SRP (сервис не должен управлять жизненным циклом HTTP-клиента) и делает код жёстко связным: подменить LLM-провайдер через DI невозможно. Создание клиента вынесено в отдельную реализацию `IAnalyserLlmClient`.
