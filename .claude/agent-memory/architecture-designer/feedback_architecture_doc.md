Файл `docs/ARCHITECTURE.md` существует и является живым документом проекта VictorySearcher.

**Why:** Пользователь явно указал, что файл должен оставаться актуальным и обновляться при изменении архитектурных решений.

**How to apply:** При любом обсуждении, которое меняет архитектуру — новый слой, новая интеграция, смена технологии, новый паттерн — обновить `docs/ARCHITECTURE.md`. Файл намеренно краткий (≤150 строк), без мелких деталей — писать только КЛЮЧЕВОЕ.
