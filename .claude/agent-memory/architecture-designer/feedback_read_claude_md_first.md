Перед планированием или проработкой архитектуры (любой фичи, модуля, системы) — **всегда сначала читать `CLAUDE.md`** проекта.

**Why:** CLAUDE.md содержит ключевые правила, структуру проекта, ссылки на важные документы (TASK.md, ARCHITECTURE.md, ai-collaboration.md) и описание сервисов. Без этого контекста архитектурные решения могут противоречить уже принятым соглашениям.

**How to apply:** В начале каждой сессии планирования/архитектуры:
1. Определить, для какого проекта/сервиса пишется план
2. Прочитать `CLAUDE.md` именно того проекта/сервиса (не обязательно корень репозитория — может быть в подпапке)
3. По ссылкам из CLAUDE.md — прочитать связанные документы (`docs/TASK.md`, `docs/ARCHITECTURE.md` и т.п.)
4. Только после этого — предлагать решения и задавать уточняющие вопросы
