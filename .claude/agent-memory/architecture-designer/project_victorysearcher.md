## Цель
Внутренний HR-инструмент для отдела АБП. Две независимые фичи:
1. **Скоринг резюме** — рекрутёр создаёт вакансию, загружает PDF/DOCX резюме → LLM ранжирует
2. **Аналитика рынка** — ежедневный сбор вакансий с HH + SuperJob, зарплатная статистика по целевым ролям

## Стек
- C# .NET 8 (Clean Architecture Monolith)
- PostgreSQL + EF Core
- Hangfire (фоновые задачи + dashboard)
- polza.ai (OpenAI-совместимый LLM провайдер)
- HH официальное API (api.hh.ru)
- SuperJob официальное API (api.superjob.ru) — второй источник
- PdfPig + DocumentFormat.OpenXml — парсинг резюме

## Авторизация
Один аккаунт из appsettings.json → JWT. Без регистрации, без ролей.

## Деплой
Локально на машине предприятия (Docker Compose). Не облако.

## Нефункциональные требования
- Автономность (фоновые задачи по cron)
- Уважение rate limits внешних API (задержки 1-2с, кэш 24ч)
- Данные хранятся локально (безопасность)

**Why:** Тестовое задание на 3 дня, оценивается инженерная зрелость и умение работать с ИИ.
**How to apply:** При любых архитектурных советах помнить про монолит, .NET 8, и жёсткий дедлайн.
