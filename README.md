# VictorySearcher

Внутренний инструмент для HR-отдела и аналитиков коммерции. Закрывает две болевые точки: ручной просмотр сотен резюме и ручной сбор данных о рынке труда.

---

## Сервисы

### Скоринг резюме

Рекрутёр создаёт вакансию, загружает резюме — система в фоне ранжирует их по релевантности с помощью LLM. На выходе: отсортированный список кандидатов с оценками и обоснованием на русском языке. Резюме с критическими несоответствиями выделяются отдельно.

### Аналитика рынка труда

Автономный сбор данных о вакансиях по заданным ролям из нескольких источников. Работает по расписанию без ручного вмешательства. Показывает зарплатные вилки, динамику по времени, топ востребованных навыков и активность рынка по каждой роли.

---

## Стек и архитектура

**Бэкенд:** C# / .NET 8 — основной стек команды, выбран для скорости разработки и поддержки.

**Архитектура:** монолит с Clean Architecture. Сервис разворачивается локально, нагрузка невысокая — монолит проще в деплое и отладке. Слоистая структура обеспечивает читаемость кода и возможность менять внешние интеграции (LLM-провайдер, источники данных) независимо от бизнес-логики.

**Деплой:** Docker Compose — всё поднимается одной командой, данные хранятся локально.

---

## Быстрый старт

```bash
git clone <repo-url>
cd VictorySearcher
docker compose up -d
```

Сервис доступен по адресу `http://localhost:5000`.
