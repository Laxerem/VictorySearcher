# VictorySearcher

Внутренний инструмент для HR-отдела и аналитиков коммерции, который автоматизирует две рутинные задачи: отбор резюме и сбор данных о рынке труда.

## О проекте

Рекрутёры тратят часы на ручной просмотр сотен резюме, а аналитики — на сбор зарплат и требований по вакансиям из разных источников. VictorySearcher закрывает обе боли:

- **Скоринг резюме** — рекрутёр создаёт вакансию и загружает резюме, система ранжирует кандидатов по релевантности с помощью LLM и выдаёт отсортированный список с оценками и обоснованием на русском языке.
- **Аналитика рынка труда** — автономный сбор вакансий по заданным ролям из нескольких источников по расписанию. Показывает зарплатные вилки, динамику, востребованные навыки и активность рынка.

## Сервисы

Проект состоит из двух сервисов. Подробности по каждому — в его локальном README.

| Сервис | Роль в проекте | Документация |
|--------|----------------|--------------|
| **VictorySearcher.Service** | Бэкенд: скоринг резюме через LLM, фоновый сбор аналитики, REST API. | [README](VictorySearcher.Service/README.md) |
| **VictorySearcher.Web** | Веб-интерфейс: создание вакансий, загрузка резюме, просмотр результатов и аналитики. | [README](VictorySearcher.Web/README.md) |

## Технологический стек

- **Бэкенд**: C# / .NET 8
- **Фронтенд**: React + TypeScript (Vite)
- **Деплой**: Docker Compose

## Как запустить

```bash
git clone <repo-url>
cd VictorySearcher
cp .env.example .env   # заполнить ключи LLM и учётные данные
docker compose up -d
```

Сервис доступен по адресу `http://localhost:5000`.
