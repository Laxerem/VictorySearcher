# Концепция дизайна — VictorySearcher

> Документ для разработки. Описывает **общий стиль** будущего интерфейса,
> а не его реализацию. Решения здесь — основание для токенов, типографики и
> компонентов (см. соседние файлы).

## Что мы оформляем

Внутренний инструмент компании Victory Group для HR и коммерции. Две независимые
функции под одним URL:

1. **Скоринг резюме** — рекрутёр создаёт вакансию, загружает резюме, получает
   ранжированный список кандидатов с баллами (overall / experience / skills /
   extra), текстовым обоснованием и списком красных флагов.
2. **Аналитика рынка** — автономно собранные данные по ролям с HH и SuperJob:
   зарплаты, динамика, топ-навыков, число вакансий.

**Аудитория:** внутренние пользователи-профессионалы (рекрутёры, аналитики),
которые работают с инструментом часами и каждый день. Не маркетинговый сайт —
рабочая среда. Один тестовый аккаунт, без регистрации и ролей.

**Главная задача интерфейса:** дать рекрутёру быстро **доверять** ранжированию и
действовать по нему — а аналитику читать плотные данные без усталости.

## Метафора: приборная панель

Продукт измеряет — присваивает кандидату числовую оценку и обосновывает её. Поэтому
визуальный язык строится вокруг идеи **измерительного прибора / инженерной консоли**,
а не яркого SaaS-дашборда. Сдержанность, точность, выровненные числа, спокойный
тёмный корпус, по которому «бежит» один сигнальный цвет данных.

Это прямое прочтение референсов Victory Group (почти чистый монохром, тонкие
границы, плотная сетка, крупный жирный капс) — но переосмысленное для рабочего
инструмента, а не для лендинга.

## Принятые решения (развилки, согласованные с заказчиком)

| Развилка | Решение | Следствие |
|----------|---------|-----------|
| Цвет | **Монохром + цвет = данные** | База строго ч/б/графит. Хроматический цвет появляется только как смысл: величина балла, статусы, красные флаги. Цвет несёт информацию, не украшает. |
| Тема | **Только тёмная** | Один тёмный режим. Проще в поддержке, цельный фирменный вид. |
| Характер | **Нейтральный инструмент** | Никаких подиумов, медалей, «лидерборда». Балл — это данные. Тема «Victory» живёт только в логотипе/бренде, не в UI-метафоре. |
| Заголовки | **Капс только в крупном** | Узкий жирный капс — для крупных экранных заголовков (фирменный жест из референсов). Весь рабочий интерфейс — обычный регистр, читаемый гротеск. |

## Принципы

1. **Цвет = смысл.** Если элемент цветной — он что-то означает (сила совпадения,
   тревога, статус задачи, свежесть данных). Декоративного цвета нет.
2. **Числа выровнены.** Баллы, зарплаты, счётчики, даты набраны моноширинным с
   табличными цифрами — колонки выстраиваются по разрядам. Это и читаемость, и
   «приборный» характер.
3. **Тишина вокруг сигнала.** Корпус (фон, границы, текст-хром) максимально
   спокойный; внимание держит только данные и единственный сигнальный оттенок.
4. **Плотность без тесноты.** Инструмент для профессионалов — информации много,
   но ритм отступов и хайрлайн-границы держат её разборчивой.
5. **Эффекты минимальны.** Анимация — только функциональная (наведение, фокус,
   раскрытие строки, прогресс фоновой задачи). Никакого амбиентного движения.
   `prefers-reduced-motion` уважается.

## Сигнатурный элемент: ScoreGauge

Один запоминающийся элемент, вытекающий из сути продукта — **измерительная шкала
балла**. Компактный горизонтальный «прибор», который показывает overall 0–100 и
его составляющие (experience / skills / extra) сегментами, моноширинными цифрами
и единственным сигнальным оттенком. Он живёт в каждой строке кандидата и
разворачивается в детальной карточке.

Тот же примитив-«прибор» переиспользуется в аналитике для зарплатной вилки
(min — median — max). Одна визуальная грамматика связывает обе функции продукта.

## Осознанный отказ от «светофора» на балле

Overall-балл **не** красится в зелёный/жёлтый/красный по принципу «хорошо/плохо».
«Хорошо» зависит от пула откликов на конкретную вакансию — это решает рекрутёр.
Инструмент показывает **величину** сигнала (один оттенок, по интенсивности), а
дисквалифицирующие проблемы выносит отдельной осью — красными флагами. Это
честная продуктовая позиция: прибор показывает измерение, человек судит.

## Самокритика концепции (чтобы не свалиться в шаблон)

ИИ-дизайн часто скатывается в «near-black фон + один кислотный акцент». Чтобы это
был **выбор**, а не дефолт:

- акцент — не неоновый, а **десатурированный приборный синий**, и привязан к
  данным, а не к декору;
- балл сознательно **не** красится светофором (см. выше);
- типографика — конкретная инженерная пара (IBM Plex Sans + Plex Mono) с
  условным капс-дисплеем, мотивированная темой «измерения», а не дефолтный Inter;
- сигнатура (шкала-прибор) выведена из предмета (баллы), а не из украшения.
