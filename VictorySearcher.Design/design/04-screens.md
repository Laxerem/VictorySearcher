# Экраны — VictorySearcher

Каркасы ключевых экранов (ASCII — для проработки композиции, не пиксель-в-пиксель).
Опираются на токены и компоненты из соседних файлов.

## Логин

Один аккаунт, JWT. Центрированная карточка на `--ink-900`.

```
┌──────────────────────────────────────────────┐
│                                                │
│                 ◇ VICTORY                      │
│              SEARCHER  (d-lg, капс)            │
│                                                │
│        ┌──────────────────────────┐            │
│        │ Логин                     │            │
│        │ [____________________]    │            │
│        │ Пароль                    │            │
│        │ [____________________]    │            │
│        │ [   Войти  (primary)   ]  │            │
│        └──────────────────────────┘            │
│        Внутренний инструмент Victory Group     │
└──────────────────────────────────────────────┘
```

## Адаптив / качество

- Хром (рейл/бар) сворачивается в бургер на узких экранах; таблицы → карточки.
- Видимый фокус везде; `prefers-reduced-motion` уважается; контраст AA на тексте.
- Числовые колонки не переносятся, выравнивание вправо сохраняется.
