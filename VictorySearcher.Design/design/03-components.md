# Компоненты — VictorySearcher

Инвентарь компонентов будущей дизайн-системы и правила их оформления через токены
([01-tokens.md](01-tokens.md)). Это спецификация стиля, не код.

## Каркас приложения (App shell)

- **Верхний бар** (липкий, `--z-sticky`): логотип Victory слева → контекст
  (текущая вакансия / роль) → аккаунт справа. Фон `--ink-850`, нижняя граница
  `--line`.
- **Левый узкий рейл**: переключение двух доменов — «Скоринг» и «Аналитика» —
  плюс вложенные разделы. Иконки + подпись `label`. Активный пункт помечен
  сигнальным синим (1px левый маркер `--signal-500` + `--text-100`).
- **Рабочая область**: фон `--ink-900`, контент в панелях `--ink-800`.

«Хром» неподвижен, контент — «экран прибора».

## Базовые элементы

### Кнопки
| Вариант | Фон | Текст | Граница | Где |
|---------|-----|-------|---------|-----|
| Primary | `--signal-700` → hover `--signal-500` | `--text-100` | — | Главное действие (Запустить скоринг) |
| Secondary | `--ink-700` | `--text-100` | `--line-strong` | Вторичное |
| Ghost | прозрачный | `--text-300` → hover `--text-100` | — | Третичное, в плотных зонах |
| Danger | прозрачный → hover `--alert-bg` | `--alert` | `--alert` | Удаление |

Радиус `--r-md`, высота 36px (компакт 28px), sentence case, без капса. Фокус —
кольцо `--focus-ring`.

### Поля ввода / textarea / select
Фон `--ink-700`, граница `--line`, в фокусе `--line-strong` + кольцо. Радиус
`--r-sm`. Подпись — `label` сверху. Текст ошибки — `--alert`, `body-sm`.

### Загрузка резюме (file-drop)
Пунктирная зона `--line-strong`, при drag-over — `--signal-700` + `--signal-900`
подложка. Список загруженных файлов: имя (`body`), размер (`num-sm`), статус
парсинга чипом. Поддержка PDF/DOCX, множественная.

### Чип / тег
Прямые скруглённые пилюли (`--r-sm`), фон `--ink-750`, текст `label`,
`--text-300`. Прямая отсылка к пилюлям-тегам из референсов (Лидогенерация,
Репутация…). Применение: навыки, категории, фильтры. Цветной чип — только если
несёт статус (warn/alert/ok).

### Таблица (ядро интерфейса)
Плотная, липкая шапка (`--z-sticky`, фон `--ink-850`), хайрлайн-строки `--line-soft`,
hover-строка `--ink-750`. Числовые колонки — `--font-data`, выравнивание вправо,
tabular-nums. Сортировка по клику на заголовок (индикатор сигнальным). Это основа
и для ранжированного списка кандидатов, и для аналитических таблиц.

## Сигнатура: ScoreGauge

Измерительная шкала балла — главный узнаваемый элемент. Два режима.

**Компактный** (в строке кандидата): горизонтальный сегментированный бар overall
0–100, залит по интенсивности из ряда `--score-*`; справа — число `num`
моноширинным. Ширина фиксирована, чтобы строки выстраивались в «прибор».

```
┌───────────────────────────── ScoreGauge (compact) ──────────────┐
│  �safik▰▰▰▰▰▰▰▰▰▱▱▱▱   72   ⚑2                                    │
│  └ заливка по --score-*  └num  └флаги (warn)                      │
└──────────────────────────────────────────────────────────────────┘
```

**Развёрнутый** (детальная карточка): крупный overall `num-xl` + три суб-шкалы
сегментами с подписями и максимумами:

```
OVERALL                                       72 / 100
▰▰▰▰▰▰▰▰▰▰▰▰▰▰▱▱▱▱▱▱

experience  ▰▰▰▰▰▰▰▰▱▱▱▱   38 / 50
skills      ▰▰▰▰▰▰▰▱▱▱     29 / 40
extra       ▰▰▱▱           соответствует / частично / нет
```

Суб-шкалы используют тот же ряд `--score-*`. Подписи — `label`, числа — `--font-data`.
`extra` может быть качественным (соответствует/частично/нет), а не числовым.

Тот же примитив рендерит **зарплатную вилку** в аналитике (min — median — max),
обеспечивая единый язык между фичами.

## Скоринг — специфичные

### Строка кандидата
`#ранг` (`num`, `--text-500`) · имя (`h-md`) · ScoreGauge compact · индикатор
красных флагов · «развернуть». Клик раскрывает деталь (анимация `--dur`).

### Красный флаг
Бейдж `--warn` (мягкое несоответствие) / `--alert` (жёсткий дисквалификатор) с
иконкой и кратким текстом. Резюме с флагами также попадают в отдельный список
несоответствий (вкладка/фильтр). Цвет здесь — это **ось тревоги**, отдельная от
балла.

### Панель обоснования (reasoning)
Длинный русский текст от LLM. `body`, мера ~70–80 симв., `--text-300`. Заголовок
панели `h-lg`. Спокойная типографика — это то, чему рекрутёр должен доверять и что
читает целиком.

### Статус фоновой задачи
Скоринг идёт в фоне. Тонкий прогресс-бар (`--signal-500`) + текст «Оценено N из M».
Завершение — статус `--ok`. Без спиннеров-каруселей; одно спокойное движение.

## Аналитика — специфичные

### KPI-плитка (stat tile)
Крупное число `num-lg/xl` + подпись `label` + дельта (стрелка, `--ok`/`--alert`
по знаку — это **системная** оценка тренда, допустимо). Панель `--ink-800`,
`--border-hair`.

### Графики (рамки)
Монохромная сетка (`--line-soft`), данные — сигнальным синим. Минимум декора.
- **Динамика ЗП** — линейный график по снимкам времени (min/median/max линиями
  разной интенсивности `--score-*`).
- **Топ-навыков** — горизонтальный бар-чарт частоты, заливка `--signal-700`.
- **Зарплатная вилка** — примитив ScoreGauge (min—median—max).
- **Конкуренция** — счётчик вакансий/компаний, `num-lg`.

### Свежесть данных
Подпись «Обновлено: …» (`num-sm`, `--text-500`). Если данные устарели (>24ч) —
`--warn` метка. Свежие — `--ok`. Привязано к автономности сбора.

## Системное

- **Тосты** (`--z-toast`): нейтральный/ok/warn/alert, `--elev-2`, авто-скрытие.
- **Модалка / дровер** (`--z-overlay`, `--elev-2`, `--r-lg`): подтверждения,
  детальные карточки.
- **Вкладки / пагинация**: активная вкладка — нижняя граница `--signal-500`.
- **Пустые состояния**: `d-md` заголовок + `body` подсказка + действие. Текст —
  приглашение к действию, не «мрачное настроение» (см. правила копирайтинга).
- **Логин**: один аккаунт. Центрированная карточка, логотип Victory, `d-lg`
  заголовок капсом, два поля, primary-кнопка «Войти». JWT.

## Голос интерфейса (копирайтинг)

- Кнопки называют действие: «Запустить скоринг», «Загрузить резюме», «Войти».
  Действие сохраняет имя через весь поток (кнопка «Войти» → ничего постороннего).
- Ошибки объясняют, что произошло и как починить; не извиняются и не расплывчаты.
- Пустой экран — приглашение действовать («Создайте вакансию, чтобы начать
  скоринг»), а не настроенческая заглушка.
- Имена — по тому, что контролирует пользователь, не по устройству системы.
  «Резюме», «Вакансия», «Роль» — не «джоба», не «энтити».
- Регистр предложений, без филлеров, тон деловой и спокойный.
