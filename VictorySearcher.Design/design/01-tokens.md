# Токены — VictorySearcher

Тёмная тема, единственная. Все значения — отправная точка для CSS-переменных.
Хроматика только функциональная (см. [00-concept.md](00-concept.md)).

## Цвет

### Нейтрали — корпус (фон, поверхности, границы, текст-хром)

Графитовая лестница со слегка холодным подтоном.

| Токен | HEX | Назначение |
|-------|-----|-----------|
| `--ink-900` | `#0A0B0D` | Фон страницы |
| `--ink-850` | `#0F1114` | Фон вложенных зон, «провалы» |
| `--ink-800` | `#141619` | Поверхность карточки / панели |
| `--ink-750` | `#1A1D22` | Приподнятое / hover-поверхность |
| `--ink-700` | `#22262D` | Поле ввода, active-поверхность |
| `--line-soft` | `#1E2228` | Очень тихий разделитель |
| `--line` | `#262A31` | Хайрлайн-граница (база) |
| `--line-strong` | `#333842` | Граница в фокусе/наведении |
| `--text-100` | `#F3F5F8` | Первичный текст |
| `--text-300` | `#B6BDC7` | Вторичный текст |
| `--text-500` | `#868E9A` | Приглушённый / подписи |
| `--text-700` | `#5A616B` | Disabled / очень тихий |

Машинный блик (опционально, для «фрезерованного» края поверхности, из реф. №3):
`--edge-highlight: rgba(255,255,255,0.04)` — 1px внутренняя верхняя подсветка.

### Сигнальный синий — единственный хроматический «характер»

Приборный, десатурированный. Активные состояния, ссылки, кольцо фокуса, верх
шкалы балла. **Не** неоновый.

| Токен | HEX | Назначение |
|-------|-----|-----------|
| `--signal-100` | `#BFE6F2` | Светлый акцент-текст на тёмном |
| `--signal-300` | `#7FCDE0` | Hover-акцент |
| `--signal-500` | `#46A6C4` | База: ссылки, активное, фокус, высокий балл |
| `--signal-700` | `#2C6E85` | Приглушённый акцент / границы активного |
| `--signal-900` | `#16323D` | Заливка-подложка (tint) |

`--focus-ring: var(--signal-500)` — кольцо фокуса всегда видимое (2px + offset).

### Шкала балла — величина (low → high)

Последовательный ряд «силы сигнала»: от нейтрального серого к сигнальному синему.
Валентность-нейтральный (не светофор). Маппинг 0–100 → корзины или непрерывная
интерполяция между крайними.

| Токен | HEX | Диапазон (ориентир) |
|-------|-----|---------------------|
| `--score-0` | `#4A5159` | низ (серый) |
| `--score-1` | `#557083` | |
| `--score-2` | `#4D8CA8` | середина |
| `--score-3` | `#46A6C4` | |
| `--score-4` | `#6FC9DD` | верх |

### Статусы — тревога/система (отдельная ось от балла)

Только для системных смыслов и красных флагов, **никогда** для валентности балла.

| Токен | HEX | Назначение |
|-------|-----|-----------|
| `--warn` | `#D9A441` | Внимание: красный флаг, мягкое несоответствие, устаревшие данные |
| `--warn-bg` | `#2A2415` | Подложка warn |
| `--alert` | `#CC5B4E` | Жёсткий дисквалификатор, ошибка |
| `--alert-bg` | `#2A1816` | Подложка alert |
| `--ok` | `#5FB39A` | Системный успех: задача завершена, данные свежие (десатур., не неон) |
| `--ok-bg` | `#15241F` | Подложка ok |

> `--ok` — только для **системного** статуса (задача/свежесть), не для оценки
> кандидата. Зелёного на балле нет.

## Типографика → токены

Семейства (подробно в [02-typography.md](02-typography.md)):
```
--font-display: "Saira Condensed", "Oswald", system-ui, sans-serif;  /* капс, крупное */
--font-ui:      "IBM Plex Sans", system-ui, sans-serif;              /* рабочий UI */
--font-data:    "IBM Plex Mono", ui-monospace, monospace;            /* числа, табличные цифры */
```
`--font-data` всегда с `font-variant-numeric: tabular-nums`.

## Радиусы (низкие — инженерный вид)

| Токен | px | Где |
|-------|----|----|
| `--r-0` | 0 | Структурные разделители, крупные хайрлайн-панели |
| `--r-sm` | 4 | Инпуты, чипы, мелкие элементы |
| `--r-md` | 6 | Кнопки, карточки |
| `--r-lg` | 10 | Модалки, крупные оверлеи |

## Границы и тени

```
--border-hair: 1px solid var(--line);
--border-active: 1px solid var(--line-strong);
--elev-1: 0 1px 2px rgba(0,0,0,0.4);          /* карточка */
--elev-2: 0 8px 24px rgba(0,0,0,0.5);          /* поповер, модалка */
```
Тёмная тема опирается на **разницу светлоты поверхностей + хайрлайн**, тени
минимальны.

## Движение (минимум)

```
--dur-fast: 120ms;
--dur:      180ms;
--ease:     cubic-bezier(0.2, 0.6, 0.2, 1);
```
Разрешённые анимации: hover/active состояний, кольцо фокуса, раскрытие/сворачивание
строки кандидата, прогресс фоновой задачи скоринга. Всё остальное — без движения.
При `prefers-reduced-motion: reduce` переходы отключаются.
