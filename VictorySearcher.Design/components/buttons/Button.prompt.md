Sharp-cornered, uppercase, wide-tracked action button — use for primary CTAs and form submits.

```jsx
<Button variant="primary" size="lg">Хочу больше клиентов</Button>
```

Variants: `primary` (light fill, dark text — the main CTA), `secondary` (hairline outline on dark), `ghost` (text only). Sizes `sm` / `md` / `lg`. Use `fullWidth` for form submit rows. Always uppercase copy.
