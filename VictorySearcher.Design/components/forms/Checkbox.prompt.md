Square custom checkbox with a label, used for option lists (e.g. "Выберите интересующее направление").

```jsx
<Checkbox label="Лидогенерация" defaultChecked />
<Checkbox label="SEO-продвижение" onChange={(v) => ...} />
```

Controlled (`checked` + `onChange`) or uncontrolled (`defaultChecked`). Checked state fills the box light with a dark tick.
